# INFO2180 Lab 4

This is Lab 4 for Jordan Morais-Duke

## Run

With PHP installed, open a terminal in this folder and run:

```sh
php -S localhost:8080
```

Visit http://localhost:8080. Alternatively, place this folder in XAMPP's htdocs folder and visit http://localhost/info2180-lab4/.

## Exercises

- Exercise 1: Original superhero endpoint and unchanged starter array.
- Exercise 2: AJAX fetch and alert, preserved in the exercise commit.
- Exercise 3: AJAX search by full name or alias; blank searches list all heroes. Results appear in #result with escaped output and a not-found message.

Names and aliases match without regard to case; surrounding whitespace is ignored.
